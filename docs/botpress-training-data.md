## 📚 Knowledge Base Content

### **1. Platform Overview**
```
Q: What is LeEnglish TOEIC Platform?
A: LeEnglish is a comprehensive TOEIC learning platform that helps students prepare for TOEIC exams through lessons, exercises, practice tests, flashcards, and interactive learning materials.

Q: What features does the platform offer?
A: The platform offers:
- Interactive lessons and exercises
- TOEIC practice tests with scoring
- Flashcard study system
- Progress tracking dashboard
- Blog with learning tips
- User feedback system
- Mobile app support
```

### **2. User Navigation Help**
```
Q: How do I start learning?
A: After logging in, visit your Dashboard to see your progress. Then go to Lessons to start with structured learning materials, or try Test Selection for practice exams.

Q: Where can I find practice tests?
A: Click on "Test Selection" in the sidebar to choose from different TOEIC test types including listening, reading, and full practice tests.

Q: How do I track my progress?
A: Visit your Dashboard to see your learning statistics, test scores, and completed lessons. You can also check Test History for detailed results.
```

### **3. Technical Support**
```
Q: I'm having trouble logging in
A: Try resetting your password using the "Forgot Password" link on the login page. If issues persist, contact support through the Feedback page.

Q: Why can't I hear audio in tests?
A: Make sure your browser allows audio playback and your volume is turned up. Try refreshing the page or using headphones.

Q: How do I report a bug?
A: Use the Feedback feature in the sidebar to report issues. Provide details about what you were doing when the problem occurred.
```

### **4. Learning Guidance**
```
Q: I'm new to TOEIC, where should I start?
A: Start with Lessons to learn TOEIC basics, then practice with Exercises. When ready, try simple practice tests before attempting full TOEIC simulations.

Q: How often should I practice?
A: For best results, practice 30-60 minutes daily. Use Flashcards for vocabulary building and take practice tests weekly to track improvement.

Q: What's the difference between exercises and tests?
A: Exercises are learning-focused with immediate feedback. Tests simulate real TOEIC conditions with scoring and time limits.
```

### **5. Account & Features**
```
Q: How do I change my profile information?
A: Click on your profile icon in the sidebar, then select "Profile" to edit your information.

Q: What are the different user roles?
A: - Student: Access all learning features
- Collaborator: Can create questions and content  
- Admin: Full platform management access

Q: How do I become a collaborator?
A: Contact platform administrators through the Contact page to request collaborator access for content creation.
```
